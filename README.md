# TaskFlow

A focused personal task manager built with React, TypeScript, and Vite.

## Scripts

- `npm run dev` - start the development server
- `npm run build` - type-check and build for production
- `npm run preview` - preview the production build
- `npm run typecheck` - run the TypeScript compiler only

## Features

- Create, edit, complete, and delete tasks
- Priority, due date, search, filters, and sorting
- Undoable delete and "clear completed" via toast actions
- Light/dark theme with local persistence and no flash on load
- Cross-tab synchronisation of tasks and theme
- Keyboard shortcut: press `n` anywhere (outside a field) to add a task
- Responsive layout and accessible controls
